# /claude-code-toolkit:project-setup

Shortcut for full cross-platform setup.

## Configuration
- context: fork
- agent: init

## Instructions

Run the init agent with `target both`.

If `$ARGUMENTS` is present, append it after the target and preserve scope semantics from `/claude-code-toolkit:setup`.

Examples:
- `target both full setup`
- `target both update`
- `target both rules only`
