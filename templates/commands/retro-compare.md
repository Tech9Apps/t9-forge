# Retro Compare

Compare current and previous retrospective signals.

## Instructions

### Gather repository activity
```bash
git log --oneline --decorate -30
```

### Summarize trend
- Throughput trend (up/down/stable)
- Quality trend (defect/churn signals)
- Team workload concentration trend

### Output
- Three wins
- Three risks
- Three concrete next-week adjustments
