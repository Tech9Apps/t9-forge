# /retro

Generate an engineering retrospective from repository activity.

## Instructions

### 1. Analyze activity window
- Default to current week unless timeframe is provided.
- Extract commit, author, and diff-level patterns.

### 2. Compute actionable metrics
- Throughput (commits, LOC, test ratio).
- Quality trend (fix ratio, hotspot churn).
- Collaboration (contributors, ownership concentration).

### 3. Build retrospective output
- Team wins.
- Risks or process bottlenecks.
- Concrete next-week improvements.

### 4. Output style
- Specific and evidence-based.
- Balanced: highlight both strengths and growth opportunities.
