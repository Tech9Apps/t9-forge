# /plan-design-review

Run a design-first review and produce a report without changing code.

## Instructions

### 1. Evaluate first impression
- Describe what the UI communicates at first glance.
- Identify the first three visual focal points.
- Provide a one-word verdict.

### 2. Audit design system consistency
- Typography scale and hierarchy quality.
- Spacing rhythm and layout hierarchy.
- Color usage, contrast, and semantic consistency.
- Interaction states and motion behavior.

### 3. Detect generic/UI-slop patterns
- Repetitive layout templates.
- Unclear hierarchy or visually flat sections.
- Inconsistent component polish.

### 4. Score and prioritize
- Provide `Design Score` and `UI Slop Score` (A-F).
- List top 5 fixes with severity and expected impact.

### 5. Output
- Save/report findings only.
- Ask whether to proceed with `/qa-design-review` for fixes.

Do not modify code from this skill.
